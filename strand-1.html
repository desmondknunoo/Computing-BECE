Computer Systems

  • A computer system includes hardware, software, data, users and procedures.
  • Fourth-generation computers use microprocessors and became smaller, faster and more reliable.
  • Fifth-generation computers focus on AI, parallel processing and natural language ideas.
  • Next-generation ideas include quantum computing and perceptual computing.

Input, Output and Storage

  • Input devices: keyboard, mouse, scanner, barcode reader, QR reader, RFID reader.
  • Output devices: monitor, printer, projector, Braille printer, thermal printer, 3D printer.
  • Storage devices: hard disk, SSD, flash drive, memory card, optical disc and cloud storage.
  • Manual input devices need human action directly. Automatic input devices can capture data more directly from codes or cards.

Technology in the Community

  • Technology tools support learning, communication, record keeping and business.
  • Assistive technology helps users with disabilities, for example screen readers and voice recognition tools.
  • Adaptive technology modifies devices or software so they suit the user better.
  • Portable devices such as phones and smart watches affect daily life strongly.
  • E-waste must be managed responsibly through safe disposal and recycling.

Health, Safety and Desktop Skills

  • Health issues include eye strain, back pain, neck pain and repetitive strain injury.
  • Safety issues include loose cables, exposed wires, spills, bad lighting and overheating.
  • Good practice: sit upright, take breaks, use document holders and avoid overloading sockets.
  • Desktop skills include file management, user accounts, file extensions and device drivers.

Quick Compare

  • HDD uses moving parts; SSD uses flash memory.
  • Health is about the body; safety is about avoiding accidents.
  • Assistive is specially designed help; adaptive is modified help.

Exam-safe Examples

  • Components of a computer system: hardware and software.
  • Input devices: keyboard and mouse.
  • Output devices: monitor and printer.
  • Storage devices: hard disk, SSD and flash drive.

Strand 3 - Chapter 2

Internet, Social Media and Email

This chapter explains how internet tools are used for communication, learning and sharing, together with the risks that come with them.

Start Chapter Next Chapter

Main Ideas

  1. Browser, search engine and URL
  2. Social media types
  3. Email features
  4. Benefits and risks of online communication

Basic Internet Terms

  • A browser is software used to open web pages.
  • A search engine helps users find information online.
  • A URL is the address of a web resource.

Correct Compare

Google Chrome is a browser. Google Search is a search engine. A web address like https://example.com is a URL.

Social Media Types

  • Social networking: Facebook, LinkedIn, WhatsApp
  • Microblogging: X or Twitter, Tumblr
  • Photo sharing: Instagram, Snapchat, Pinterest
  • Video sharing: YouTube, Vimeo, Facebook Live

Email Features

Feature Use
Attachment Add a file to the email
Address Book Store contact information
Reply Answer only the sender
Reply All Answer everyone copied in the message
Forward Send the message to another person
CC / BCC CC is visible to all; BCC hides copied recipients

Benefits Risks

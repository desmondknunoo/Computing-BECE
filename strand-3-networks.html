Strand 3 - Chapter 1

Computer Networks

This chapter focuses on network hardware, topologies, network types, the OSI model, the internet, the web, IP addresses and DNS.

Start Chapter Next Chapter

Must-know Terms

  1. Server and client
  2. Switch, router and modem
  3. Bus, star, ring and mesh
  4. PAN, LAN, MAN and WAN
  5. OSI model, IP and DNS

Network Meaning and Hardware

  • A computer network is a group of connected devices that share resources and information.
  • A server provides resources; a client requests them.
  • A switch manages traffic inside a local network.
  • A router connects one network to another.
  • A modem helps provide internet connection through signal conversion.

Topologies

Topology Key Idea
Bus All devices share one main cable
Star Devices connect to one central device
Ring Devices form a circular path
Mesh Many devices connect directly to each other

Network Types

  • PAN covers a small personal range.
  • LAN covers a small local area like a lab.
  • MAN covers a city or large town.
  • WAN covers a very wide area, such as the internet.

Internet, WWW, IP and DNS

  • The internet is the global network of networks.
  • The World Wide Web is the collection of websites on the internet.
  • An IP address identifies a device.
  • DNS changes domain names into IP addresses.
  • IPv4 and IPv6 are internet addressing systems.

OSI Model Basics

  • Application layer = user interface and services
  • Transport layer = segmentation and delivery
  • Data link layer = local delivery and error checking
  • Physical layer = signals or bits

One Good Exam Sentence

The OSI model organises communication into layers so devices can send data in a standard and reliable way.

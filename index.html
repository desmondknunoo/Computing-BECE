Strand 1

Introduction to Computing

This strand is the base. It covers the computer system itself, how technology is used in society, and how to stay safe and healthy while using digital tools.

1. Computer Systems and Generations

A computer system is the complete working setup of hardware, software, data, users and procedures used to process data into information.

  • Fourth generation: microprocessors, smaller size, higher speed, better reliability.
  • Fifth generation: AI, parallel processing, natural language ideas, smarter machines.
  • Next-generation trends: quantum computing, perceptual computing and more intelligent interfaces.
  • Perceptual computing: computers respond to voice, gesture, movement or other natural inputs.
Remember If a question asks for components of a computer system, safe answers are hardware and software. If it asks for devices, give examples like keyboard, mouse, monitor or printer.

2. Devices, Storage and Desktop Skills

  • Input devices: keyboard, mouse, scanner, barcode reader, graphic tablet, QR reader, RFID reader.
  • Output devices: monitor, printer, projector, Braille printer, thermal printer, 3D printer.
  • Storage devices: hard disk, SSD, flash drive, memory card, optical disc, cloud storage, network storage.
  • Desktop skills: file and folder management, file extensions, permissions, user accounts, drivers and updates.
Pair Main Difference
HDD vs SSD HDD has moving parts; SSD uses flash memory and is faster.
Cloud vs Network Storage Cloud usually uses the internet; network storage is shared through a local network.
File vs Folder A file stores data; a folder stores files and other folders.
Driver vs Application A driver helps the operating system control hardware; an application helps the user do work.

3. Technology in the Community

  • Technology tools can support learning in every subject: spreadsheets, presentation software, simulations, virtual museums and coding tools.
  • Assistive technology helps people with disabilities perform tasks more easily, for example screen readers and voice recognition tools.
  • Adaptive technology modifies existing tools so they fit the user better.
  • Portable devices such as phones, tablets and smart watches affect communication, learning and business every day.
  • Technology can help solve community problems such as transport, health, business records and communication.
  • Computers also create e-waste, so proper recycling and responsible disposal matter.
Common exam link Questions on assistive vs adaptive technology, portable devices, online services, and environmental effects all belong here.

4. Health and Safety

  • Health issues: eye strain, neck pain, back pain, hearing problems, repetitive strain injury and poor posture.
  • Safety issues: loose cables, overloaded sockets, spilled liquids, too much heat, bad lighting and loud speakers.
  • Use a document holder, sit upright, take breaks, keep the screen at a good level and protect the eyes from glare.
  • Keep the work area neat and do not touch exposed wires.
  • Device drivers should be installed and updated so hardware works correctly.

Quick Rule

Health is about the effect on the body. Safety is about preventing accidents and damage.

Strand 2

Productivity Software

This strand is about using software to create, edit, present, organise and publish information clearly.

1. Word Processing

  • Word processor: software used to create, edit, format and print text documents.
  • Basic skills include insert, select, delete, move text, find and replace, undo, spell check and language setting.
  • Formatting includes font style, size, colour, case, alignment, line spacing, borders and shading.
  • Advanced skills include tables, merge cells, split cells, hyperlinks, headers, footers, page numbers and page orientation.
  • Basic 9 adds screenshots, SmartArt, charts, audio, video and hyperlinks.

2. Presentation Software

  • Used to prepare slides for speaking, teaching or reporting.
  • Know themes, templates, special characters, Slide Master, design tools and review tools.
  • Pictures, shapes, SmartArt, screenshots, tables, charts, audio and video can all be inserted.
  • Transition: effect between slides.
  • Animation: effect on an object inside a slide.
Exam trap Do not mix up transitions and animations. The first changes slides. The second changes items on a slide.

3. Desktop Publishing

  • Desktop publishing software is used to create flyers, invitations, adverts, cards and other layout-based documents.
  • Know the meaning and importance of DTP packages such as Publisher and InDesign.
  • Be familiar with Publisher ribbons such as Home, Insert, Design and Text Box.
  • Learn templates, margins, orientation, pictures, text boxes, overflow, layout and colour balance.
  • At Basic 9 level, learners also critique layout, mechanics, colour use and suitability for purpose.

4. Electronic Spreadsheet

  • Spreadsheets store data in rows and columns.
  • Know the interface, cell data types, alignment, merge and wrap, borders, shading, margins, headers and footers.
  • Formula is a user-written expression. Function is a built-in formula like SUM or AVERAGE.
  • Common functions: SUM, AVERAGE, COUNT, COUNTA, COUNTIF, MAX, MIN.
  • Advanced work includes validation, sorting, filtering, styles, themes, templates, macros, pivot tables and pivot charts.

Shortcut Corner

  • Ctrl + C copies.
  • Ctrl + V pastes.
  • Ctrl + K inserts a hyperlink in Word.
  • Ctrl + D opens the font dialog in Word.
  • Ctrl + Shift + N creates a new folder.

Worked Spreadsheet Example

  • Highest mark: =MAX(B2:B6)
  • Lowest mark: =MIN(B2:B6)
  • Total mark: =SUM(B2:B6)
  • Average mark: =AVERAGE(B2:B6)

If a question asks for the difference between save and save as: Save updates the same file, while Save As creates a new name, location or format.

Strand 3

Communication Networks

This strand builds from basic networks in Basic 7 to internet structure, security, e-commerce and blogging in Basic 9. It is a high-priority exam area, so study the terms carefully.

1. Computer Networks

A computer network is a group of connected devices that share data, resources and services.

  • Hardware: server, client, hub, switch, cable, router, modem.
  • Topologies: bus, star, ring and mesh.
  • Types of networks: PAN, LAN, MAN, WAN and WLAN.
  • Internet is the global network of networks. WWW is the collection of web pages accessed through the internet.
  • IP address identifies a device on a network. DNS changes domain names into IP addresses.
  • Basic 9 adds e-commerce, online payments, QR payments, bitcoin and eLearning.
Network Type Idea Example
PAN Very small personal range Phone linked to earbuds
LAN Small local area School computer lab
MAN Covers a city or large town Networks across one metropolis
WAN Covers a very wide area The internet

2. OSI Model and Data Communication

The OSI model explains how data moves from one computer to another in layers. You do not always need every layer in detail, but some layers are common exam targets.

Layer Main Job
Application Gives the user a way to type, read and use the message.
Transport Breaks data into segments and manages end-to-end delivery.
Data Link Checks for errors in frames during local delivery.
Physical Converts data into bits, signals or electrical form for transmission.
Mock paper clue Physical layer = signals or bits. Transport layer = segmentation. Data link = error checking. Application layer = user interface.

3. Internet, Email and Social Media

  • Know the difference between browser, search engine and URL.
  • Social media types include social networking, microblogging, photo sharing and video sharing.
  • Email features include attachment, address book, reply, reply all, forward, forward all, cc and bcc.
  • Advantages of social media: communication, publicity, collaboration and learning.
  • Risks of social media: cyberbullying, privacy breaches, identity theft, misinformation and distraction.
Email Field Use
To Main receiver
CC Copies others openly
BCC Copies others secretly
Subject Short title of the email

4. Information Security

  • Confidentiality: only authorised people should see the data.
  • Integrity: data should stay correct and unchanged unless properly updated.
  • Availability: data should be accessible when needed.
  • Major data threats: interruption, interception, modification and fabrication.
  • Protection methods: authorisation, authentication, encryption and decryption.
  • Also learn copyright, patent, trademark, piracy, cyberbullying, cyberstalking, digital footprint and digital shadow.
Threat Meaning Possible Protection
Interruption Data or service is stopped Backup, redundancy, maintenance
Interception Unauthorised person sees data Encryption, authentication
Modification Data is changed wrongly Integrity checks, controlled access
Fabrication False data is added Authorisation, audit trails

5. Searching and Evaluating the Web

  • Use accurate spelling and strong search phrases.
  • Search operators such as AND, OR and NOT help narrow or widen results.
  • Check more than one search engine where possible.
  • Use open learning sites and virtual learning environments for study.
  • Blogging is a Basic 9 topic: know the importance of blogs, blog content and publication steps.

Website Evaluation Rule

Test a page with five checks: Accuracy, Credibility, Content, Current and Functionality.

Strand 4

Computational Thinking

This is the weakest area for many learners, so slow down here and make sure each idea is clear. Most errors happen because students try to memorise terms without understanding what they do.

1. Programming Basics

  • Programming means giving instructions to a computer so it can solve a problem.
  • Variable: a named storage space whose value can change.
  • Constant: a value that does not change while the program runs.
  • Data types: integer, float, string, character and boolean.
  • Expression: a combination of values and operators that gives a result.
  • Statements: complete instructions such as assignment, input, output or decision statements.
  • Operators: arithmetic, relational and logical.
Data Data Type
1.28 Float
"Ama" String
A Character
-1 Integer
A true or false statement Boolean

2. Number Systems and Operator Precedence

  • Computers process data in binary.
  • Be able to convert between decimal, binary and sometimes hexadecimal.
  • Use the order of operations when solving expressions.
  • In many programming contexts, // means integer division and mod means remainder.

Worked Example

5//2 + 4*2^3 + 6 mod 4

  • 2^3 = 8
  • 4*8 = 32
  • 5//2 = 2
  • 6 mod 4 = 2
  • Total = 36

Decimal to Binary

Decimal 13 becomes binary 1101 because 13 = 8 + 4 + 1.

3. Algorithms, Decomposition and Abstraction

  • Algorithm: a step-by-step method for solving a problem.
  • Decomposition: breaking a big problem into smaller parts.
  • Abstraction: focusing only on the important details.
  • Sequence: instructions happen in order.
  • Selection: the program chooses between options.
  • Iteration: the program repeats steps.
  • Linear search: checking one item after another until the value is found.
Write better algorithm answers Start each step with an action word such as Start, Input, Calculate, Display and Stop.

4. Flowcharts and Pseudocode

A flowchart is a diagram that shows the steps of a process using standard symbols. Pseudocode is a plain-language way of writing the same logic.

Terminator Start or Stop
Process Calculation or action
Decision Yes/No choice
Input / Output Read or display data

Pseudocode: Sum of Two Numbers

  • Start
  • Input first number
  • Input second number
  • Set sum = first number + second number
  • Display sum
  • Stop

5. Robotics

  • Robots are programmable machines that can sense, decide and act.
  • Main robot parts: controller, sensors and mechanical parts or actuators.
  • Applications: manufacturing, transport, surgery, education, laboratories, packaging and imaging.
  • Advantages: speed, accuracy, repeatability, work in dangerous places.
  • Disadvantages: cost, job displacement, over-dependence, malfunction risk and hacking risk.

Asimov's Three Laws

  1. A robot must not harm a human being, or allow a human being to come to harm.
  2. A robot must obey human orders unless those orders conflict with the first law.
  3. A robot must protect itself unless that conflicts with the first or second law.

6. Artificial Intelligence

  • AI is the ability of a computer or machine to perform tasks that normally need human intelligence.
  • Important areas: machine learning, artificial neural networks, expert systems, virtual reality, augmented reality and mixed reality.
  • Expert system: a knowledge-based system that uses rules such as IF-THEN to make decisions.
  • Weak AI handles a narrow task. Strong AI would think more like a human across many tasks.
  • AI uses data, so ethics, privacy and fairness matter.
Important idea Human intelligence, animal intelligence and machine intelligence do not work in exactly the same way. Machines are fast and consistent but need data, rules and training.
Exam Method

How to Write Better Answers

For Definitions

  1. State what the term means directly.
  2. Add one short use or example if needed.
  3. Avoid circular answers such as "A browser is used for browsing."

For Differences

  1. Put both items in one sentence.
  2. Use the word whereas.
  3. Compare the real feature, not just the spelling.

For Lists and Functions

  1. Write one clear point per line.
  2. Use standard terms from class or the syllabus.
  3. If asked for a function, say what the device or software does.

Strand 4 - Chapter 3

Pseudocode and Problem Solving

Pseudocode is a bridge between normal language and real code. It helps you express the logic of a solution clearly without worrying yet about the exact syntax of a programming language.

Start Pseudocode Next Chapter

  1. What pseudocode is

  3. Worked solutions for common BECE questions
  4. How to move between flowcharts and pseudocode

What Pseudocode Is

  • Pseudocode is a simple way of writing program logic using everyday words and structured steps.
  • It is not tied to one specific programming language.
  • It should still be orderly, clear and easy to follow.
Best habit Write one instruction per line. Keep the sequence clean.

Useful Action Words

  • Start
  • Input
  • Set or Calculate
  • If / Else
  • Display
  • Stop

Worked Example 1: Sum of Two Numbers

  • Start
  • Input first number
  • Input second number
  • Set sum = first number + second number
  • Display sum
  • Stop

Worked Example 2: Even or Odd

  • Start
  • Input number
  • If number mod 2 = 0, display "Even"
  • Else display "Odd"
  • Stop

Worked Example 3: Largest of Two Numbers

  • Start
  • Input first number
  • Input second number
  • If first number > second number, display first number
  • Else display second number
  • Stop

Worked Example 4: Daily-Life Algorithm

If the question asks for a real-world algorithm, do not panic. Use ordinary actions in the correct order.

Making Tea

  • Start
  • Boil water
  • Put tea bag in cup
  • Pour hot water into cup
  • If sugar is needed, add sugar
  • If milk is needed, add milk
  • Stir and serve
  • Stop

From Flowchart to Pseudocode

  • Read the symbols in order from start to stop.
  • Convert each process box into an action line.
  • Convert each decision diamond into an If or If-Else statement.
  • Keep the output from the flowchart in the pseudocode.

From Pseudocode to Flowchart

  • Start and Stop become terminators.
  • Input and Display become input/output symbols.
  • Calculations become process boxes.
  • If statements become decision diamonds.

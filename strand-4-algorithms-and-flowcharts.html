Algorithms and Flowcharts

This chapter explains how to think through a problem before coding it. Good algorithms are clear, logical and arranged in the correct order.

Core Meanings

  • Algorithm: a step-by-step method for solving a problem.
  • Decomposition: breaking a big problem into smaller parts.
  • Abstraction: focusing on the important details and ignoring unnecessary ones.

Simple Decomposition Example

If you want to organise a class trip, you can break the work into transport, money, student list, permission and time plan.

Sequence, Selection and Iteration

  • Sequence: instructions run one after another in order.
  • Selection: a decision is made between different actions.
  • Iteration: a set of steps is repeated.
Concept Daily-Life Example
Sequence Wash hands, dry hands, sit down and eat
Selection If it is raining, carry an umbrella
Iteration Clap five times

Flowchart Symbols

Terminator Start or stop
Process Action or calculation
Decision Yes or no choice
Input / Output Read or display data

Why Flowcharts Matter

  • They make a process easier to understand.
  • They help you spot mistakes before coding.
  • They show the order of actions clearly.
  • They are useful for explaining logic to others.

Linear Search

A linear search checks one item after another until the target value is found or the list ends.

Example

To find 7 in 2, 5, 7, 9, check 2, then 5, then 7. Stop when 7 is found.

How to Write Better Algorithm Answers

  • Use short action lines, not long paragraphs.
  • Start with Start and end with Stop.
  • Use Input, Process and Display clearly.
  • Keep the steps in the exact working order.

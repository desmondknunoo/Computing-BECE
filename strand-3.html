Sub-strand 1

Computer Networks

A network exists when devices are linked together so they can share data, software, storage or other resources.

Key Hardware and Terms

  • Server: a computer that provides services or resources to other computers.
  • Client: a computer that requests services from a server.
  • Switch: connects devices inside a local network and sends data to the correct device.
  • Hub: sends incoming data to all connected devices.
  • Router: connects different networks together.
  • Modem: helps a network connect to an internet service through signal conversion.
Fast memory hook Switch = smarter local traffic. Router = traffic between networks. Modem = internet connection signal conversion.

Network Topologies

Topology Main Shape Important Point
Bus One main cable Simple, but a main cable problem can affect the whole network.
Star All devices connect to one central device Easy to manage, but if the central device fails, the network is badly affected.
Ring Devices form a closed loop Data moves around the ring in order.
Mesh Many direct links between devices Very reliable, but more expensive and complex.

Types of Networks

Type Meaning Example
PAN Personal Area Network Phone and smart watch
LAN Local Area Network School lab or office
MAN Metropolitan Area Network One city network
WAN Wide Area Network The internet

One Good Sentence

A LAN connects devices in a small area, whereas a WAN connects devices across very large distances.

Internet, Web, IP and DNS

  • Internet: the worldwide network of networks.
  • World Wide Web: websites and web pages accessed through the internet.
  • IP address: a numeric address that identifies a device.
  • DNS: changes names like example.com into IP addresses, just like a phonebook connects names to numbers.
  • IPv4 uses shorter numeric addresses. IPv6 was introduced to support many more devices.
OSI Focus

Data Communication and the OSI Model

The OSI model is a common exam topic because it explains how communication is organised into layers.

Layers You Should Know Safely

Layer Exam-safe function
Application User-facing services like typing or reading a message
Transport Breaks data into segments and manages delivery
Data Link Checks frames and handles local delivery errors
Physical Converts data into bits or signals for transmission

Why the OSI Model Matters

  • It divides communication into simpler parts.
  • It helps different hardware and software work together.
  • It makes troubleshooting easier because each layer has a role.
  • It supports standard communication between devices from different makers.
Sub-strand 2

Internet, Social Media and Email

Browser, Search Engine and URL

  • Browser: software for opening web pages, such as Chrome or Firefox.
  • Search engine: a web tool for finding information, such as Google or Bing.
  • URL: the address of a resource on the web.

Compare These Correctly

A browser opens pages. A search engine helps you find pages. A URL is the address of the page.

Social Media Types

  • Social networking: Facebook, LinkedIn, WhatsApp.
  • Microblogging: X or Twitter, Tumblr.
  • Photo sharing: Instagram, Snapchat, Pinterest.
  • Video sharing: YouTube, Vimeo, Facebook Live.
Benefits Fast communication, publicity, collaboration, business promotion and learning.
Risks Cyberbullying, privacy breaches, identity theft, scams, misinformation and addiction.

Email Features

Feature Meaning
Attachment Adds a file to an email
Address Book Stores contact details
Reply Responds only to the sender
Reply All Responds to everyone copied in the email
Forward Sends the email to another person
CC / BCC CC is visible to all recipients; BCC hides copied recipients
Sub-strand 3

Information Security

This section moves from basic security ideas in Basic 7 to more specific threats and online behaviour in Basic 9.

The CIA Triad

  • Confidentiality: data is protected from unauthorised viewing.
  • Integrity: data stays correct and trustworthy.
  • Availability: data or services are accessible when needed.

Simple Examples

  • Confidentiality: password-protected student records
  • Integrity: preventing secret editing of exam scores
  • Availability: school portal stays online during registration

Threats and Protection Methods

Threat Meaning Protection
Interruption Service or data becomes unavailable Backup, maintenance, redundancy
Interception Data is seen by the wrong person Encryption, authentication
Modification Data is changed without permission Access control, integrity checks
Fabrication False data is created or inserted Authorisation, auditing, validation

Legal and Social Issues Online

  • Copyright: ownership of original creative work.
  • Patent: legal protection for inventions.
  • Trademark: symbol, name or sign that identifies a brand.
  • Piracy: illegal copying or use of protected material.
  • Cyberbullying: hurting people online repeatedly.
  • Cyberstalking: repeated harmful tracking or harassment online.
  • Digital footprint: trace of what you do online.
  • Digital shadow: data about you collected by others online.

Common Hacking Techniques

  • Phishing
  • Keylogging
  • Denial of Service attack
  • Eavesdropping
  • Malware infection
  • Password cracking
Prevention basics Use strong passwords, think before clicking links, update software, use antivirus, back up data and never share sensitive data carelessly.
Sub-strand 4

Web Technologies and Search Skills

Effective Search Techniques

  • Use exact spelling and clear keywords.
  • Use phrases instead of one weak word.
  • AND narrows the search.
  • OR widens the search.
  • NOT removes unwanted terms.
  • Compare results from more than one search engine.

Website Evaluation Checklist

  • Accuracy: Is the information correct?
  • Credibility: Who wrote it? Are they reliable?
  • Content: Does it match the topic?
  • Current: Is it up to date?
  • Functionality: Does the site work properly?

Virtual Learning Environments and Open Learning Sites

  • VLEs support self-paced learning.
  • They allow access to lessons, exercises and discussions outside the classroom.
  • Examples of open learning sites include Khan Academy, Coursera, edX and Saylor.

Blogs

  • A blog is a regularly updated website or web page that shares posts.
  • Blogs can be used by schools, clubs or individuals for news, reports and learning materials.
  • Basic steps: choose a platform, plan the content, create the layout, publish the post and invite comments.
Quick Check

Three Strong Revision Questions

Strand 3 Differentiate internet and World Wide Web. Open

Write one sentence for each term and show the difference clearly.

Answer

The internet is the global network that connects devices, whereas the World Wide Web is the collection of websites and web pages accessed through that network.

Strand 3 What is the function of BCC in email? Open

Give a direct answer and mention the hidden copy idea.

Answer

BCC sends a copy of an email to another recipient without showing that recipient's address to the main recipients.

Strand 3 State one threat and one protection method. Open

Example: use interception and encryption.

Answer

Interception is a threat in which unauthorised people view data, and encryption is a protection method that changes data into coded form so outsiders cannot read it easily.

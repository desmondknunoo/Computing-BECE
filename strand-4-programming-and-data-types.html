Programming and Data Types

This chapter builds the language of coding. If these basic terms are clear, later topics such as algorithms and pseudocode become much easier.

What Programming Means

  • A program is a set of instructions given to a computer.
  • Programming is the act of writing those instructions to solve a problem.
  • A programming language is a formal way of writing instructions, for example Scratch or Python.
  • An IDE is a software environment that helps programmers write, test and manage code.

Key Terms

Term Meaning
Variable A named value that can change
Constant A value meant to stay fixed
Expression A combination of values and operators that gives a result
Statement A full instruction such as input, output or assignment
Operator A symbol used to perform an action
Operand The value an operator works on

Data Types

Data Type What it stores Example
Integer Whole numbers 7, -1
Float Decimal numbers 1.28
String Text with many characters "Ama"
Character One letter, number or symbol A
Boolean True or false value True, False
Important note A sentence becomes a Boolean only when it is treated as a true or false statement. A normal text sentence in quotes is a string.

Variables and Constants

  • Use a variable when the value can change, for example a student's score.
  • Use a constant when the value should stay fixed, for example a pass mark.
  • Good variable names are clear and meaningful, such as studentName or totalMarks.
  • Avoid unclear names like x unless the meaning is obvious.

Example

studentScore = 68 is a variable.

PASS_MARK = 50 is a constant.

Operators and Expressions

  • Arithmetic operators: +, -, *, /, mod, //
  • Relational operators: <, >, =, <=, >=
  • Logical operators: AND, OR, NOT

Expression Example

In a + b, the operator is + and the operands are a and b.

Operator Precedence

Computers follow an order when solving expressions. A simple memory guide is BODMAS.

Worked Example

5//2 + 4*2^3 + 6 mod 4

  • 2^3 = 8
  • 4*8 = 32
  • 5//2 = 2
  • 6 mod 4 = 2
  • Total = 36

Number Systems

  • Decimal uses digits 0 to 9.
  • Binary uses only 0 and 1.
  • Hexadecimal uses 0 to 9 and A to F.
  • Computers process data in binary.

Decimal to Binary

Decimal 13 becomes binary 1101 because 13 = 8 + 4 + 1.

Decimal 10 becomes binary 1010.

Strand 2

Productivity Software

Strand 2 teaches how to produce useful work with software: documents, slides, publications and spreadsheets. This page keeps all of those tools together in one scrollable lesson.

How Strand 2 Grows

  1. Basic 7: editing and formatting in Word, PowerPoint and Excel.
  2. Basic 8: tables, hyperlinks, shapes, Publisher basics and spreadsheet functions.
  3. Basic 9: multimedia, SmartArt, data filtering, charts, validation and pivot tables.

Word Processing

  • A word processor creates, edits, formats and prints documents.
  • Editing includes insert, delete, move, find, replace and undo.
  • Formatting includes font size, colour, case, alignment, spacing, bullets, borders and shading.
  • Later topics include tables, merge and split cells, page setup, headers, footers, hyperlinks and multimedia.

Presentation Software

  • Used to organise ideas on slides for teaching or speaking.
  • Know themes, templates, special characters, Slide Master and review tools.
  • Know how to add pictures, shapes, SmartArt, screenshots, tables, charts, audio and video.
  • Transition happens between slides; animation affects items on a slide.

Desktop Publishing

  • Used for flyers, cards, invitations and adverts.
  • Know the meaning and importance of desktop publishing software.
  • Learn templates, text boxes, margins, orientation, images and document layout.
  • Publisher ribbons such as Home, Insert, Design and Text Box are important.

Spreadsheets

  • Spreadsheets organise data in rows and columns.
  • Know data types, cell formatting, merge and wrap, borders, margins, headers and footers.
  • Know formulas and functions such as SUM, AVERAGE, MAX and MIN.
  • Advanced work includes sorting, filtering, validation, styles, themes, macros and pivot tables.

Useful Reminders

  • Editing changes content. Formatting changes appearance.
  • Formula is user-written. Function is built in.
  • Save updates the same file. Save As creates a new version.

Common Commands

  • Ctrl + C copy
  • Ctrl + V paste
  • Ctrl + K insert hyperlink
  • =SUM() total
  • =AVERAGE() average
